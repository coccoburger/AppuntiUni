# Informazioni, Dati e Rappresentazioni

- **Informazione:** Il concetto astratto che si vuole rappresentare o comunicare.
- **Dato:** La codifica formale dell'informazione memorizzata e manipolata all'interno di un calcolatore.
- **Codifica e Decodifica:**
  - **Codifica:** $\text{Informazione} \longrightarrow \text{Dato}$ (rappresentazione opportuna).
  - **Decodifica:** $\text{Dato} \longrightarrow \text{Informazione}$.

---

# Tipi di Dato Strutturati

I tipi di dato primitivi (`int`, `float`, `char`) permettono di memorizzare un singolo valore. I **tipi strutturati** consentono di definire aggregazioni arbitrarie di dati.

- **Array:** Aggregano elementi **omogenei** (tutti dello stesso tipo).
- **Strutture (`struct`):** Aggregano elementi **eterogenei** (di tipi diversi).

---

# Il Costruttore `struct` in C

La parola chiave `struct` permette di definire un nuovo tipo di dato composto da uno o più campi (o membri), ciascuno con il proprio tipo e nome.

### 1. Definizione della Struttura e Dichiarazione di Variabili

Esistono due sintassi principali per definire una struttura e dichiarare variabili:

#### Approccio A: Definizione separata dalla dichiarazione

```c
// Definizione del tipo struct
struct Impiegato {
    char nome[20];
    char cognome[20];
    float stipendio;
    char codiceFiscale[17]; // 16 caratteri + 1 per il carattere nullo '\0'
};

// Dichiarazione delle variabili
struct Impiegato staff1, staff2;
```

## Conversioni di Tipo

- Quando abbiamo operandi non del tipo atteso, in C, viene effettuata una conversione automatica, o implicita, piuttosto che segnalare errore.

esempio: 
```c
int i=10;
float f=3.0,f1;
f1=i+f;
```
Nel valutare l'espressione i + f, viene:
- prima effettuata conversione di i in float
- viene effettuata la somma in float tra i e f
Anche durante l'assegnazione, il valore dell'espressione a destra dell'uguale viene convertito al tipo a sinistra
- Questo può causare troncamento e quindi perdita di informazione, oppure una trasformazione indesiderata, tipo da int a char e da float a int.

## Regole di conversione

- Si converte temporaneamente l'operando di tipo inferiore facendolo divenire di tipo superiore
- Ogni variabile di tipo char o short (con le versioni signed o unsigned) viene convertita in int
- Se dopo ci sono ancora operandi eterogenei si segue la seguente gerarchia:
 int < long < unsigned long < long < float < double

Conversione esplicita 
si usa l'operatore di casting, ad esempio:
```c
float media;
int n1=5,n2=2;
media=(float)(n1+n2)/2;
```
